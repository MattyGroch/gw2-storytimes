Privacy Policy

Last updated: March 9, 2026

Overview

GW2 Story Times is a community-driven web application that provides estimated completion times for Guild Wars 2 story missions. It consists of a public REST API and a frontend interface. We are committed to collecting as little data as possible.

Data We Collect

When you submit a time estimate or sentiment rating, the following is stored on our server:

  • Submission data — the mission ID, category (full experience or speedrun), duration in minutes, submission source, and timestamp.
  • IP hash — a one-way hash of your IP address, used solely for rate limiting (one submission per mission per category per 24 hours). Your actual IP address is not stored.

Browsing mission data and viewing time estimates does not require any personal information and no data is collected from read-only usage.

Data Stored in Your Browser

  • User Preferences — settings such as the synopsis visibility toggle are stored in localStorage to persist across sessions.

No authentication tokens, API keys, or personal identifiers are stored in your browser.

Cookies, Analytics & Tracking

This application does not use cookies, analytics services, advertising pixels, fingerprinting, or any other form of tracking. No data about your browsing behavior is collected or transmitted to any third party.

Third-Party Services

The application loads the following resources from third-party CDNs:

  • React and Babel from unpkg.com
  • Tailwind CSS from cdn.tailwindcss.com
  • Cinzel font from fonts.googleapis.com

Mission description text is sourced from ArenaNet's public Guild Wars 2 API (api.guildwars2.com) during data seeding. These services may log standard web request data (such as IP addresses) according to their own privacy policies. This application has no control over or access to that data.

Clearing Your Data

You can remove all locally stored preferences at any time by clearing your browser's site data for this domain. Submissions to the community database cannot be individually retracted as they are anonymized and aggregated.

Open Source

The complete source code for this application is publicly available on GitHub. You are welcome to audit the code to verify these claims.
